I. Общие CSS-требования (Применимо ко всем страницам)
1. Селекторы и Псевдоклассы
- Селекторы элементов, классов и комбинации: Использовать для базовой стилизации, переиспользуемых стилей и сложного таргетинга (объединение, потомки, дочерние элементы).
- Селекторы атрибутов: Применять для стилизации, основанной на подстроке в начале или конце атрибута, а также на точном значении атрибута.
- Динамические псевдоклассы: Создать различные стили для ссылок в состояниях :link, :visited, :hover, :active, а также для элементов в состоянии :focus.
- Структурные псевдоклассы: Использовать :first-child, :last-child, :nth-child для стилизации элементов в списках и таблицах в зависимости от их положения.
- Псевдоклассы форм: Стилизовать элементы формы в состояниях :enabled, :required, :disabled, :out-of-range, а также включенные флажки и переключатели (:checked).
2. Псевдоэлементы и Типографика
- Псевдоэлементы для текста: Выделить первую букву или строку абзаца в статье (::first-letter, ::first-line).
- Добавление контента: Добавить контекст в начале и конце фрагмента текста с помощью ::before и ::after.
- Списки: Оформить один из списков маркерами — символами юникода (list-style-type).
- Выделение текста: Изменять стиль при выделении текста с помощью ::selection.
- Шрифты: Подключить основной шрифт (из службы шрифтов), альтернативный и использовать семейство шрифтов.
- Текстовое оформление: Настроить отступы и поля, красную строку, межстрочный интервал, а также интервал между словами и символами.
- Преобразование текста: Оформить заголовки (или любой другой фрагмент текста) с помощью text-transform.
- Капитель: Оформить любой фрагмент капителью или использовать расширенные возможности font-variant.
- Перенос/Разрыв: Настроить перенос и разрыв слов.
3. Макет и Взаимодействие
- Медиа-запросы: Использовать для отображения страниц в зависимости от ширины и высоты области отображения (адаптивный дизайн).
- Курсор: Изменять вид курсора при наведении на кнопки.
- Фон: Настроить задний фон сайта.
- Расположение блоков: Использовать позиционирование блоков для их расположения на странице.
II. Стилизация по страницам (Специфика проекта)
1. Главная страница
- Прелоадер: Реализовать анимацию из трех пульсирующих по очереди точек (изменение цвета и размера). Разместить элемент прелоадера внизу страницы (без JS).
- Анимация: Реализовать анимацию: дом, в котором последовательно зажигаются окна, вокруг сад с деревьями, проплывают облака, открывается дверь и появляется рекламный слоган (без JS).
- Партнеры: Список компаний-партнеров оформить в виде блоков круглой формы. Настроить для них ширину, цвет, тип и тень.
- Наименование компании: Настроить шрифт и кернинг (letter-spacing).
- Последняя статья: Использовать позиционирование (position) для отображения информации о ней.
- Навигация: Область навигации по сайту должна фиксироваться при прокрутке остальной страницы (position: fixed или sticky).
2. О компании
- Логотип: Использовать трансформацию (transform) для отображения логотипа (функция на выбор).
- Сертификат/Билет: Использовать: изображения для границ из графического файла (с вендорными префиксами), фоновое изображение, градиент, z-index, настройку шрифтов и выравнивание текста.
- Остальные элементы: Настроить оформление истории по годам (списком), выделить реквизиты шрифтом. Стиль для видео/аудио выбрать самостоятельно.
3. Каталог/Услуги
Макет: Для отображения каталога использовать CSS Grid Layout, Фильтрацию сделать боковой панелью со своей полосой прокрутки.
4. Новости
- Краткое содержание: Использовать свойство overflow и многоточие (text-overflow: ellipsis) для краткой информации, которая не помещается в выделенную область.
- Текст статьи: Для отображения полного текста статьи использовать многоколоночный макет.
5. Контакты
Сотрудники: Использовать Flexbox для размещения информации о каждом сотруднике.
6. Вакансии
Макет: Использовать плавающие блоки (float) и очистку потока (clear).
7. Отзывы
Форма: Настроить шрифты на компонентах формы, используя ключевые слова, соответствующие типу компонента, и применить псевдоклассы.
8. Таблицы (Общие правила)
- Границы: Убрать двойные линии между ячейками внутри таблицы (border-collapse: collapse).
- Фон: Изменить фон в пустых ячейках.
- Заголовок: Оформить заголовок таблицы над таблицей (caption-side).
- Выравнивание: Применить горизонтальное и вертикальное выравнивание информации в ячейках и настроить расположение таблицы на странице.
- Стилизация: Стилизовать строки и столбцы.
